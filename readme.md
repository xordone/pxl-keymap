# PXL keymap
Мой вариант раскладки для клавитуры с 42 клавишами

В слое MAIN символы алфавита, для русских Ё и Ъ необходимо зажать клавиши Е и Ь соответственно.

В слое NUM цифры и F клавиши.

В слое NAV стелки, ctrl+стрелки, home, end и тп, все расположено симетрично стрелкам которые набираются из домашней позиции(jkl;).

В слое SYM символы в правой половине,  а на месте где цифры в NUM здесь символы соответствующих цифр с SHIFT.

Слой GAME попытка сделать слой для игр, как смог так и сделал))).

Слой ETC для дополнительных функций самой клавиатуры, профили BT и всё такое.

В файле <a href=" keymap.svg">kaymap.svg</a> иллюстрация раскладки.
